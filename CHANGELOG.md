# Changelog - Оптимизации Workflow

## Версия 2.0 (Оптимизированная) - 2024

### 🚀 Критические оптимизации

#### 1. Объединение запросов метаданных
- **Было:** 3 отдельных запроса к Groq API (Create Slug, Create Title, Create Meta Description)
- **Стало:** 1 объединенный запрос (Create SEO Metadata)
- **Экономия:** 66% API вызовов, ~30 секунд времени выполнения

#### 2. Добавлен узел Config
- Вынесена вся конфигурация в отдельный узел
- Использование переменных окружения (process.env)
- Упрощена настройка workflow
- **Файлы:** Config node в начале workflow

#### 3. Параллельная генерация HTML и изображения
- HTML и изображение генерируются параллельно
- Добавлен узел "Merge HTML and Image" для объединения данных
- **Экономия:** ~50% времени на этом этапе

#### 4. Улучшена обработка ошибок
- Добавлена обработка ошибок в Aggregate Research
- Логирование ошибок Google Custom Search
- Продолжение работы при ошибках отдельных запросов

#### 5. Динамический промпт для изображения
- Промпт генерируется на основе primary keyword
- Более релевантные изображения для каждой статьи

### 🔧 Технические улучшения

### ⚠️ Важные изменения для пользователя

1. **Настройка Config узла:**
   - Установите переменные окружения или обновите значения в узле Config
   - `WORDPRESS_SITE` - домен WordPress
   - `TELEGRAM_LINK` - ссылка на Telegram
   - `BANNER_URL` - URL баннера
   - `GOOGLE_SEARCH_API_KEY` - ключ Google Search API
   - `GOOGLE_SEARCH_CX` - CX Google Search

2. **Новая структура метаданных:**
   - Все метаданные (slug, title, meta description) теперь в одном узле
   - Данные доступны через `Parse Metadata` или `Merge HTML and Image`

3. **Проверка после импорта:**
   - Убедитесь, что все credentials настроены
   - Проверьте connections в визуальном редакторе
   - Протестируйте workflow на тестовой статье
